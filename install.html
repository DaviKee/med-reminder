INSTALL · 定时服药提醒

安装到你的安卓手机

包名 com.medreminder.app · 3.5 MB · Android 8.0 以上可用。安装后记得做下面那两件事，否则提醒不会响。

方式一 · 扫码直装（推荐）

手机扫一下，直接下载

用手机相机或浏览器扫左边的码，会跳到下载页，点下载即可。

下载完点开 APK，系统问「允许安装未知应用」时选允许——这是自己打包的 debug 签名包，正常提示。

http://192.168.2.23:8080/
手机必须和这台电脑连同一个 WiFi，且这个页面在下载完成前不要关闭（我开的是临时服务，关掉链接就失效）。

方式二 · 数据线 / 传文件

1
USB 调试安装

手机「设置 → 关于手机」连点版本号 7 次开开发者模式 → 开发者选项里打开 USB 调试 → 插线，手机上点「允许」→ 电脑上执行：

adb install -r "med-reminder-debug.apk"
# adb 在 %LOCALAPPDATA%/Android/Sdk/platform-tools/，装了 Android Studio 才有

插好线跟我说一声，我可以直接帮你装。

2
发文件到手机

把 med-reminder-debug.apk 通过微信 / QQ / 网盘发到手机，用手机文件管理器点开安装。

装好后 · 必做两件事
允许通知权限

第一次打开 App 会弹窗问，务必点「允许」。这是提醒能响的前提。

加电池白名单

小米 / 华为 / OPPO / vivo 会杀后台闹钟：设置 → 应用 → 定时服药提醒 → 电池选「无限制 / 不优化」，并打开「自启动」。否则提醒可能延迟几分钟。

这是 debug 签名的自测包，适合自己用或发给家人。要正式上架应用商店，需要换成 release 签名并做混淆。
