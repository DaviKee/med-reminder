## 5. 已知偏差与注意事项

### ① `build-apk.sh` 里的 `rm` 会撞删除守卫 —— 这是本机最大的坑

脚本第 240 行有 `rm -f MedReminder-v*.apk med-reminder-debug.apk`，而脚本开头是 `set -e`。
本机的删除会走 `safe-delete` 守卫（命中会打印 `[safe-delete][SAFE_DELETE_BULK_CONFIRM_REQUIRED]`），
**一旦被拦，脚本会在"APK 已编译好、但还没复制出来"的位置中断**——看起来像构建失败，其实已经成功了。

**所以我没有用 `build-apk.sh`，而是手动跑了它的每一步**（`cap sync` → `gradlew assembleDebug` → 复制产物）。
产出的 APK 就是 §1-16 那个。

→ 要不要我把脚本改成不依赖 `rm`（比如改成"覆盖同名前先移到备份目录"）？脚本是受版本控制的，改它会产生 git 差异，所以我先没动。

