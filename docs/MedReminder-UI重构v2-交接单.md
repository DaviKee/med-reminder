## 1. 改了什么（19 文件 / +518 −183）

### 1.1 设计令牌：色板与字阶整体替换

`www/css/tokens.css` **全量重写**。核心是**把撞车的语义拆开**：

| 语义 | 旧 | 新 | 为什么 |
|---|---|---|---|
| 主行动 | `#FF7A17` | `#7FE7C4` 薄荷 | 旧版橙色**同时**表示"该按"和"漏服了" —— 一个颜色两种相反含义 |
| 警示 | 同一个 `#FF7A17` | `#FF8A3D` 琥珀（新变量 `--warn`） | 语义分离后，"漏服/低库存/通知被拒"不再和主按钮抢颜色 |
| 次文字 | `#7B7F85` + `#5E6166` | `#8B8F94`（只留一档） | 实测 `#5E6166` 在深底上只有 **3.01:1**，`#7B7F85` 在卡片上 **4.32:1**、在高亮行 **3.86:1** —— 全部不达 WCAG AA。**这一档已删除** |
| 表面 | 卡片 8px 圆角细描边 | 三档明度 `#121212 → #1A1A1C → #232427`，圆角 18 | 层级靠明度差，不用投影 |

字阶：正文 14→**16**，眉标 12→11 但加粗到 600，`.h1` 28/34 600。
（`--fs` 档位机制没动，最大仍是 1.3 倍 —— 新字号在"特大"档下等于旧版的 1.49 倍，
已在既有布局上跑过，没有新增溢出风险。）

亮色主题逐个变量重定义，`theme.spec.js` 的对称性检查通过。
> ⚠️ **改任何颜色前先读 `tokens.css` 顶部注释**：CSS 里不许出现裸颜色，一律 `var(--x)`，
> 且亮色块必须逐个重定义 —— 漏一个不报错，只是那个颜色不跟着主题变。

### 1.5 工具链

1. `cap copy` 在本机必然非零退出 —— 卡在 `autoGenerateConfig` 删 `res/xml/config.xml`，

   **gradle 已成功、APK 就在 outputs 里，但没被复制到根目录**。改成 `mv` 到 `归档/apk/`
   （不经过删除守卫，旧包还能回退）。

`tests/fixed.spec.js` 改了一条断言：原来硬锁 `.time-input{height:44px}`，
改成「≥44px」—— 符合项目自己"断言查做了什么，不查怎么写"的规矩。

## 2. 四个必须先知道的设计决定

### 2.1 打卡成功用「居中大勾」而不是 toast

老人打卡后最常见的动作是**再点一次**确认到底记上没有（重复点击会走进"今天已经打过卡了"，
观感像失败）。所以加了一层不可交互的确认层：大勾 + 「已记录 14:30」，1 秒自动消失。

- 实现：`ui/toast.js` 的 `takenPop()`，只切 class，动画在 `components.css` 的 `@keyframes popIn`
- `pointer-events:none` 是硬要求 —— 它绝不能挡住下面任何东西
- 重播前 `void offsetWidth` 强制回流，连续两次打卡才都能看到动画

### 2.2 药片缩略位是**剂型图标**，不是照片

`med` 里没有药品照片（拍照打卡存的是每次服药的记录，不是药品档案）。
所以 `.medthumb` 现在按 `med.form`（剂型）给一个兜底图标：片剂=刻痕圆片 / 胶囊=胶囊 /
口服液·滴剂·喷剂=瓶 / 贴剂·软膏=贴片 / 未填=胶囊。
**将来加"给药品拍张照"，直接把 `<img>` 塞进 `.medthumb` 即可，尺寸和圆角都不用动。**

### 2.3 响铃弹层**没有**「停止」按钮

设计稿上是「稍后」大、「停止」小，但 App 里没有"停止"这个动作，只有「已服用」和「稍后」。
硬加一个"不记录就关掉"等于给漏服开后门。所以落成**两颗按钮 + 尺寸差 + 延后上限**，
没照搬设计稿的第三个按钮。要加"跳过本次"，已有的 `#dlgSkip` 走二次确认，别在这里开口子。

### 2.4 ⚠️ 与 2026-10-16「品牌蓝」的冲突 —— 需要秦老师拍板

`memory/2026-10-16-引入品牌蓝.md` 定过四色角色：**#1B5CF0 图标蓝 = 品牌/主行动**、
#E08A3C 琥珀 = 进行中、#E2564C 红 = 警示、#4EA36C 绿 = 完成。
**那套只落在 Ardot 画板，从没进过代码**（v1.5.33 拆 CSS 时仍是"零视觉回归"，代码里还是橙）。

本次 v2 用的是**薄荷 #7FE7C4 = 行动 / 琥珀 #FF8A3D = 警示**，
依据是秦老师本轮给的参考方向（"深色底 #121212 配**荧光**/低饱和主色"）与逐屏确认。
**但这两套不兼容，必须二选一。** 若决定回到品牌蓝：

```css
/* tokens.css —— 改 3 行 + 跑一遍对比度 */
--accent:#1B5CF0;      /* 深色主题 */
--on-accent:#FFFFFF;
--accent:#1B5CF0;      /* 亮色主题，--on-accent 同样是白 */
```

改完必须复核：白字 on #1B5CF0 = 5.4:1（过 AA），但**「已服用」大勾的深色描边
（`--on-accent`）会变白**，`.checkpop-ring` 的勾、`.fab` 的加号、`.step-plus` 的加号
都要一起看一遍。**另外 `--warn` 的琥珀要与品牌蓝并存**（那正是拆开语义的收益）。
