# AGC 创建应用 + 提交代理提醒申请 —— 操作卡

> **目标**：在 AppGallery Connect 建好应用实体，然后提交「代理提醒」开放能力申请。
> **前置**：华为开发者账号 + **已实名认证**（✅ 你说已做完）｜ **预计 30 分钟**
> **之后**：等 **8 个工作日** 审批

---

## 0. 一页速览

```
① 登录 AGC（developer.huawei.com）→「开发与服务」
        ↓
② 新建应用（证书、APP ID 和 Profile → APP ID → 新建）
   ⚠️ 这一步有 3 个「填了就不能改」的字段 —— 先看 §1
        ↓
③ 找到「开放能力管理」→ 点「代理提醒」→ 申请
        ↓
④ 填申请原因（用材料包 §2.1 的文案）+ 上传 2 张截图
        ↓
⑤ 提交 →「申请中」→ ⏳ 8 个工作日 → 通过后勾开关 + 保存
        ↓
⑥ 重新生成 Profile + 手动签名（见《申请材料包》§5）
```

---

## 1. ⚠️ 先想清楚：三个「定了就不能改」的东西

**这一步填错，代价是重新走一遍流程。动手前定下来。**

### 1.1 应用包名（bundleName）

| 项 | 说明 |
|---|---|
| 规则 | 小写字母 / 数字 / 点号；**不能以数字开头**；**全球唯一** |
| ⚠️ | **创建后不能改**（改了等于换应用），且**必须与工程 `AppScope/app.json5` 的 `bundleName` 完全一致**，否则签名校验失败 |
| **建议值** | **`com.davikee.medreminder`** |
| ❌ 不要用 | `com.medreminder.spike`（那是测试包，见 `spike/harmony-test/`） |

> 提示：`com.<你的标识>.<应用名>` 是最保险的写法。如果提示"包名已存在"，换一个即可（例如加 `app` 后缀）。

### 1.2 应用分类（**创建时**）

⚠️ **注意区分**：创建时选的是**大类**，只有两个选项：

| 选项 | 我们选哪个 |
|---|---|
| **普通应用** | ✅ **选这个** |
| 游戏类应用 | ❌ 不是 |

> ⚠️ 官方原文：「**设置后不支持修改，请慎重选择**」
>
> 📌 **别搞混**：药品/健康那种**细分分类**（医疗 → 药品）是**后面填上架资料时**选的，
> **不是**创建应用时选的。两份材料里我修正了这一点。

### 1.3 应用名称

| 项 | 说明 |
|---|---|
| 长度 | ≤ **15 个汉字** 或 30 个其他字符 |
| ⚠️ | **一个自然年内只能改 2 次** |
| 禁用 | "免费 / 最佳 / 促销 / ¥" 等营销词；不能用系统图标当图标 |
| **建议值** | **`药准时`**（简短、能记住）或 `MedReminder` |
| ⚠️ 上架时 | 名称需与**软著**上的名称一致（如果提交了软著） |

> 💡 如果还没想好，可以先填一个能用的（比如 `药准时`），**别为了完美卡住进度** ——
> 名字一年能改 2 次，包名才是一次性的。

## 2. 创建项目（若还没有）

**项目（Project）是"资源组织实体"，应用挂在项目下。**

```
AGC 首页 →「开发与服务」→「我的项目」→「添加项目」
  → 输入项目名称（如 MedReminder）→ 完成
```

> 📌 官方建议：**一个项目放一个应用的不同形态**，不要把不同应用塞一个项目里（会有隐私合规问题）。
> 我们只有一个应用，建一个项目就够。

---

## 3. 创建应用

**入口有两处，任选其一（我都写过，避免你找不到）：**

| 入口 | 路径 |
|---|---|
| **A（推荐）** | AGC →「开发与服务」→ 左侧「**证书、APP ID 和 Profile**」→「**APP ID**」页签 → 点「**新建**」 |
| B | 「我的项目」→ 点进项目 → 「添加应用」 |

**然后按界面填：**

| 字段 | 填什么 |
|---|---|
| **应用类型** | **HarmonyOS 应用**（⚠️ 不是"元服务" —— 官方说找不到"开放能力管理"页签时，往往就是这里选错了） |
| **应用名称** | §1.3 定好的（如 `药准时`） |
| **应用包名** | §1.1 定好的（如 `com.davikee.medreminder`） |
| **应用分类** | **普通应用** |
| **所属项目** | 选 §2 建的项目；没有就直接输入新项目名（会自动创建） |
| 设备类型 / 最低 API | 按界面默认（我们主要面向 Phone，建议至少勾 Phone） |
| 其他 | 能留空的先留空，创建后再补 |

点「**下一步 / 确定**」→ 应用创建成功，页面会显示 **APP ID**。

> 💡 **顺手记下 APP ID**（后续查资料/提工单会用到）。

---

## 4. 找到「开放能力管理」

创建完**不一定**在当前页，按下面任一路径找：

| 路径 | 操作 |
|---|---|
| **A** | 「开发与服务」→ 项目列表 → 点进项目 → **「项目设置」→「开放能力管理」页签** |
| **B** | 「APP ID」菜单 → 点**应用名称链接** → 进入「应用详情」→ 「开放能力」栏 |

⚠️ **如果两个地方都找不到"开放能力管理"** —— 官方给的解法是：
> 「若没有找到'开放能力管理'页签，请**重新创建新的 HarmonyOS 应用**/元服务。」

→ 说明应用类型选错了（选成元服务或别的形态），回 §3 重建一个 HarmonyOS 应用。

---

## 5. 提交「代理提醒」申请

在「开放能力管理」页面里：

1. 找到「**代理提醒**」卡片（它是**不可直接勾选**的能力，所以有「申请」按钮）
2. 点「**申请**」
3. ⚠️ 如果弹出「**申请前置条件**」提示框 → 说明有约束条件，确认满足后点「下一步」
4. 在「**新建业务申请**」窗口：
   - **申请原因**：用 `MedReminder-鸿蒙代理提醒-申请材料.md` **§2.1 的精简版文案**（直接复制）
   - **上传附件**（2 张截图）：
     - **代理提醒功能场景截图** → 用 `spike/harmony-test/screenshots-for-agc/` 里的
       **`04-添加药品-服药方式与间隔设置.png`**（最核心）+ `01-今日-打卡与提醒入口.png`
     - **应用分类信息截图** → 见 §6
5. 点「**提交**」

**提交后**：
- 按钮变成「**申请中**」，审批时长 **8 个工作日**
- 可到「**互动中心**」看申请状态
- 通过后：**互动中心 + 邮件通知** → 能力开关**自动开启**（或手动勾选）→ **点「保存」**

---

## 6. 怎么拿到「应用分类信息截图」

**官方指明的路径**：

```
AGC →「APP」页签 →「应用上架」→「应用信息」→ 找到「应用分类」字段 → 截图
```

**这一步要填/确认的东西**：

| 字段 | 填什么 |
|---|---|
| **应用分类** | ⭐ 一级 **医疗** → 二级 **药品**（备选：运动健康 → 健康管理） |
| 应用标签 / 描述 | 能填的先填（一句话简介：`按时提醒服药，本地保存，无需注册`） |

然后**把显示这一屏截下来**（要能看清分类字段）。

> ⚠️ **说明**：如果页面提示"需要先上传应用包"，那就**先把能填的信息填完**再截；
> 实在进不去「应用信息」页时，也可以截「应用详情 / APP ID 页面上显示分类的那一屏」，
> 并在申请原因里用文字补一句分类（不影响申请主体）。

## 7. 审批通过之后（**别漏，漏了等于没申请**）

```
① 确认能力开关已勾上 → 点「保存」
        ↓  ⚠️ 官方：「配置的开放能力信息会写入 Profile，建议在申请 Profile 前完成配置」
② 去「证书、APP ID 和 Profile」→ 重新生成并下载 Profile（.p7b）
        ↓  ⚠️ 官方：「修改开放能力配置后，原有 Profile 将失效，请重新下载」
③ 用新的 .p7b 重新签名工程
        ↓
④ 跑验证：bash spike/harmony-test/verify-reminder-after-sign.sh
        ↓
⑤ 看到 `1) publishReminder OK  id=...` → ✅ 通了
```

详见《`MedReminder-鸿蒙代理提醒-申请材料.md`》**§5 手动签名**。

## 8. 常见问题

| 问题 | 处理 |
|---|---|
| **找不到「开放能力管理」** | 应用类型选错了 → 重建一个 **HarmonyOS 应用**（不是元服务） |
| **提示团队项目数/应用数达上限** | 账号下的历史项目太多 → 删掉不用的（项目设置页底部有「删除项目」） |
| **提示包名已存在** | 全球唯一，换一个（如 `com.davikee.medreminder`） |
| **应用分类填错了** | ⚠️ **不能改**，只能重建应用（所以 §1 让你先想清楚） |
| **申请提交后长时间没消息** | 8 个工作日是正常时长；可在互动中心查询/催办 |
| **申请被驳回** | 看驳回理由（一般是场景说明不够）→ 补充材料重提 |
| **要收费吗** | ❌ 注册、实名、建应用、开放能力申请、上架 **全免费** |

## 9. 诚实边界

- **AGC 界面会随版本调整**，本卡给的是**路径与字段名**，以实际界面为准。
- **§6「应用分类信息截图」的获取方式**，官方只给了路径没给细节；
  **如果那个页面要求先上传应用包**，按 §6 的备选方案处理。
- **创建应用是否需要"先有上架权限"**：有社区资料提过"实名后需发邮件到
  `agconnect@huawei.com` 申请上架权限"—— 但**不一定需要**。**按 AGC 界面提示走，弹了再发。**
- **申请文案与分类建议是给出的建议稿**，可按审核反馈调整。
