官方给的路径是明确的，但由于**应用尚未上架**，市场上查不到，必须在 AGC 后台截：

```
1. 登录 AppGallery Connect

4. 找到「应用分类」字段（应为：医疗 → 药品）

```

### ⚠️ 如果「应用分类」是空的

第 4 条驳回意见说「**当前应用市场无法查询您的应用分类信息**」——
**可能不只是"没截图"，而是"分类还没填"**。若在「应用信息」里找不到分类字段或它是空的：

1. 先在「应用信息」里把**分类填好并保存**：
   - 首选 **医疗 → 药品**（最精准，且直接命中代理提醒准入的"医疗类"）
   - 备选 **运动健康 → 健康管理**
2. 保存后再截图（即"填好分类 + 已保存"的状态）

> 💡 **为什么要填**：代理提醒的准入判断**看的是行业分类**
> （准入清单：工具/商务/效率/金融理财/教育/**生活服务**/旅游/**医疗**/**运动健康**/游戏）。
> 分类为空，审核端无法判定我们是否在准入范围内 —— **这很可能也是驳回的原因之一**。
