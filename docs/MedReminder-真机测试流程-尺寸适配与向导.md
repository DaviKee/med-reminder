# MedReminder 真机测试流程 —— 尺寸适配 / 录入向导 / TTS（v1.5.32+）

> 适用版本：**v1.5.32 及以上** ｜ 2026-10-15 整理
> 测试机型：小米 13（Android 15+，验安全区新方案）+ 主力机（Android 14-，验兼容不变）
> 记录方式：每项后标 ✅ / ❌；❌ 的**必须截图**（截图会带版本卡便于对账）

---

## 0. 准备（2 分钟）

1. 安装 `MedReminder-v1.5.32-2026-10-15.apk`（有原生改动，**建议先卸载旧版再装**）。
2. 首次打开，进「记录 → 调试与验收」，确认版本卡显示 **v1.5.32 · 2026-10-15**。
   ❌ 版本号不对 → 后面全部不用测，先确认装没装对。
3. 手机「设置 → 显示 → 字体大小」保持**默认**（专项测试在 §5 再改）。

---

## A. 十分钟快测（每天装新包必做）

| # | 操作 | 预期 |
|---|---|---|
| A1 | 打开 App 看首页 | 顶部内容在状态栏**下方**，状态栏区域与页面同色，无黑条、无大空白 |
| A2 | 看底部导航 | 导航条不顶到手势条/导航键，按钮都能点 |
| A3 | 记录 → 二级菜单 → 月历与统计 / 数据备份，各开一次 | 浮层完整显示，能滚动，右上角能关掉 |
| A4 | 药品页 → 点 + 新建药品 → **连走 5 步**（随便填）→ 保存 | 每步「下一步」都能点；第 5 步有「保存药品」；保存后回到列表 |
| A5 | 「记录 → 调试与验收」看「影子文件」一行 | ✓ 正常 · 最近写入时刻（刚保存过应该是几秒前） |

**A 组全过 = 本次两连修验收完成**，B/C/D 组按需细测。

---

## B. 显示区域 / 尺寸适配专项

> 核心标准：**内容完整可见、无异常空白、左右不破版**。在小米 13 与主力机各过一遍。

| # | 操作 | 预期 |
|---|---|---|
| B1 | 首页上下滚动 | 顶部日期行完整（不被状态栏压住）；底部导航完整 |
| B2 | 药品页上下滚动 | 最后一条药品能看到，不被手势条遮住 |
| B3 | 打开任一浮层（月历/数据/显示） | 浮层四边不贴边也不异常缩；底部不与导航重叠 |
| B4 | 新建药品第 1 步，点药名输入框弹键盘 | 键盘不把输入框顶出屏幕外；收起键盘后布局复原 |
| B5 | 记录 → 显示 → 切「浅色」主题 | 状态栏图标自动变**深色**（浅背景上看得清）；切回「深色」恢复白图标 |
| B6 | 两台手机对比 | 布局一致，只有安全区高度随机型不同（这是正确的） |

## C. 录入向导完整流程（新建 + 编辑）

| # | 操作 | 预期 |
|---|---|---|
| C1 | 新建：填名称「测试药 A」，选剂型「胶囊」→ 下一步 | 剂型选中态高亮；**单位自动填「粒」** |
| C2 | 第 2 步：剂量 1，点「餐后」快捷说明 → 下一步 | 备注框自动填「餐后」；再点一次「餐后」可清空 |
| C3 | 第 3 步：选「按固定时刻」 | 出现时刻列表，默认 8:00/20:00 两条，可改可删可加 |
| C4 | 第 4 步：选「每周」→ 勾一三五 | 周 chips 高亮；一天没选时有警告文案 |
| C5 | 第 5 步：选「短期疗程」→ 点「服 7 天」 | 开始=今天、结束=今天+6；提示行显示共 7 天 |
| C6 | 保存 | 回到药品页；「测试药 A」出现在**短期用药**组，带「还剩 7 天」 |
| C7 | 编辑「测试药 A」到第 5 步 | 出现「病好了，提前结束这个药」按钮 |
| C8 | 点提前结束 → 确认 | 药移入「已结束」组；列表不再显示剩余天数 |
| C9 | 再新建一个：第 5 步选「长期服用」保存 | 出现在**长期服药**组 |

## D. 语音播报（TTS）

| # | 操作 | 预期 |
|---|---|---|
| D1 | 记录 → 显示 → 语音·播报 → 点「开」 | 当场念一句「语音播报已打开」 |
| D2 | 等下一次提醒弹窗（或临时把某药时刻改成 2 分钟后） | 弹窗出现时念「该吃药了，药名，时刻」 |
| D3 | 点「已服药」 | 语音**立刻停**，不拖到后台念完 |
| D4 | 显示设置切「关」 | 之后弹窗不再出声 |

---

## E. 系统字体放大（尺寸适配的唯一未知项）

1. 手机设置 → 显示 → 字体大小调到**最大**；
2. 回 App 过一遍 A 组；
3. 重点看：文字是否变大但**版式不破**（无横向滚动、无文字出框、按钮没被顶变形）；
4. 测完把字体调回默认。

❌ 破版 → 截图（要拍到具体的破版位置）。

---

## F. 核心回归（提醒主链路，防止新功能碰坏老功能）

| # | 操作 | 预期 |
|---|---|---|
| F1 | 删光测试药，真实添加今天的药并打卡 | 正常排程，今日页出现剂量列表 |
| F2 | 到点等提醒（或「调试与验收」发测试提醒） | 通知/弹窗正常响；弹窗打卡正常 |
| F3 | 「调试与验收」看通知诊断 | 系统排程条数与今日应提醒次数一致 |
| F4 | 杀掉 App 重开 | 数据完好；今日打卡记录还在 |
| F5 | 记录 → 数据备份 → 导出，再导入回显 | 备份可导出；导入校验通过 |

## 反馈格式（发现问题时报这些，缺一难定位）

1. **版本号**（调试与验收卡上那行）；
2. **机型**（如 小米 13 / 主力机型号）；
3. **截图**（拍全屏幕，别裁剪 —— 安全区问题必须看到状态栏和手势条）；
4. **做了什么**（一句话，例："向导第 4 步点下一步没反应"）。

---

## 已知非缺陷（别报）

- 鸿蒙端「测试提醒」会立即响（≤60s 走立即发布，语义差异）；
- 鸿蒙代理提醒通知上只有「关闭/稍后」按钮，没有「已服用」；
- 平板/折叠屏上 App 是居中的 430px 手机版式（刻意设计，不铺满全屏）；
- 旧手机（Android 14-）状态栏图标在浅色主题下仍为白色（黑底路径，正常）。
